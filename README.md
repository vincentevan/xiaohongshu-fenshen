# 小红书分身
macOS 小红书双账号工具

在 macOS 上，更轻松地使用两个小红书账号。

小红书分身是一款本地运行的 Mac 桌面应用。它把两个独立的账号页面放进同一个窗口，让你无需在浏览器窗口之间来回切换。

主要功能

- 双账号独立使用，支持左右双栏和单账号大屏切换
- 每个账号拥有独立的登录状态、浏览数据和导航按钮
- 支持未读提醒、日间与夜间显示模式
- 支持自动收起和悬浮按钮，方便随时隐藏或找回窗口
- 可将视频保存到本地“下载”文件夹

隐私与数据

应用在你的 Mac 上运行，不需要额外的云端账号。两个账号分别使用独立的本地网页数据存储，彼此不会共用登录状态。登录在应用内的网页中完成；应用不采集或上传你的账号密码。

支持环境

- Apple Silicon Mac（M 系列芯片）
- macOS 14 或更新版本
目前不提供 Intel Mac 或 Windows 版本。

安装

1. 从仓库的 Releases 页面下载最新 DMG 安装包。
2. 打开 DMG，将“小红书分身.app”拖入“应用程序”。
3. 从“应用程序”启动，在左右两栏分别登录账号。

如果 macOS 首次打开时提示无法验证开发者，请确认安装包来源可信，再前往“系统设置 → 隐私与安全性”查看打开选项。
